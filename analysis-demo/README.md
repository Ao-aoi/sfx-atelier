# Audio Analysis Lab

ブラウザ内で音声を読み込み、基本的な音響特徴と周波数帯域を確認する実験用デモです。

## 起動方法

Cloudflare Pagesなどの静的ホスティングで `analysis-demo/` を公開するか、ローカルHTTPサーバーで開きます。

```bash
python -m http.server 8000
```

ブラウザで `http://localhost:8000/analysis-demo/` を開いてください。MP3 / WAVを選択すると解析します。

## 現在できること

- ブラウザ内での音声デコード（ファイルはアップロードしない）
- RMS、スペクトル重心、スペクトルロールオフ、ゼロ交差率、スペクトル変化の計算
- 簡易テンポ推定
- 低域・中域・高域のエネルギー比率と、帯域別の試聴
- スペクトログラム表示
- 残響・反復・ステレオ幅などの兆候をヒューリスティックに表示
- 分析結果のJSON出力

## 重要な制約

このデモの「帯域分解」は楽器ごとの音源分離ではありません。低域・中域・高域には複数の楽器が混ざります。Demucsなどの音源分離モデルを追加すると、ボーカル・ドラム・ベース・その他のようなステム分離を別工程として実装できます。

また、残響・ディレイ・歪みは演奏や音源自体の特徴でも似た数値が出るため、現状のエフェクト欄は確定判定ではなく兆候の表示です。楽器名や感情の推定もまだ行いません。

## 次の分析段階

5. 分析結果をsfx-atelierのレイヤー／シーケンスへ変換
