# M5 の測定：物理から作った discard の変換と、M2 の discard との比較

エディタの「物理から作る」欄（`web/src/ui/physics.ts`）と同じ計算を、`web/test/physics.browser.test.ts` の「差の表」で出す（Chromium、48kHz）。

## 条件

- 物理の録音：`packages/physics` の `DISCARD_SCENE`（牌 26×35×20mm・12g の樹脂を、布を張った卓に底の高さ 6cm から落とす）、`DISCARD_SOUND`、雑音の種 1。前後の無音を除き、山 -1dB に正規化
- 変換：M4.5 の `convert`（`packages/fit`、既定の予算：縮めた JSON 3072 バイト・層 24）。変換後はランタイムで描画（種 1）
- 基準：M2 のバンク `bank/mahjong.sfxbank.json` の `discard` から残響の送りを外した乾いた音
- 距離：`packages/analysis` の `distance`（M4.5 の測定と同じ指標）

## 結果

変換後：7 層・806 バイト（完了条件の 3KB 以下を満たす）

| 比べるもの | スペクトル差 dB | 山の差 dB | 立ち上がりの差 ms | 長さの差 ms |
| --- | --- | --- | --- | --- |
| 物理の録音 ↔ 変換後 | 8.4 | -8.0 | 1 | 363 |
| 物理の録音 ↔ 基準 | 13.4 | -3.5 | 2 | -94 |
| 変換後 ↔ 基準 | 13.5 | 4.5 | 1 | -457 |

## 分かったこと

- 変換は動き、3KB 以下に収まる。ただし M2 の音の変換（スペクトル差 4〜6dB）より差が大きい（8.4dB）。変換後は山が 8dB 低く、363ms 長い。卓の低いモード（約 120Hz）は STFT 1024 点の分解能（47Hz）に近く、減衰の推定が長めに出ている見込み。`fit` で低い成分の減衰を測り直すのが次の手
- 物理の録音は基準より暗い（重心 約 1.7kHz）。布の柔らかさ（接触の時間 0.4ms）で、牌の高いモードがほとんど励起されないため。材質の数値（`DISCARD_SOUND`）を A/B で聞きながら直す
