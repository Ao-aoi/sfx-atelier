両方を同じ乱数の種で OfflineAudioContext（48kHz）に描画し、種 1〜5 の平均を取った。乱数を引く順番（白色雑音 → 残響 → 揺らぎ・雑音の読み出し位置）が両方で同じなので、揺らぎの無い音は波形まで一致する。

- 長さ：最大音量から −60dB を最後に上回る時刻

## 差が出ている音と理由

`discard`・`call`・`kan`・`deal`（牌の `clack` を使う音）だけ差がある。どれも音量の推移の差は 0.5dB 未満。

1. **揺らぎの分布**：基準は高さの倍率を一様（例 ±4%）に揺らし、新しい形式はセントで一様（±68 セント）に揺らす。幅はほぼ同じで、分布の形が少し違う
2. **低い「コトッ」の行き先**：基準は 190Hz → 95Hz の行き先（95Hz）を揺らぎで動かさない。新しい形式は `toHz` も一緒に動かす

## 許容差（目安）

`packages/compare/test/report.test.ts` で、音量の推移 1dB・重心 3%・長さ 10ms・最大音量 0.5dB を超えたら落ちるようにした。最後は耳で決める（`/ab/` のページ）。

## 大きさ

`bank/mahjong.sfxbank.json`（16 音・楽器 14 個）から id を落とした JSON は 5251 B（gzip 後 1081 B）。今の `sfx.ts` の合成部分（約 300 行）の代わりになる。
